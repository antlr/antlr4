[notes]
The Go target prefixes the getter for a whole list with All, so one allFoo and
a list of foo both want AllFoo(), whether they are rules or tokens. Renaming a
getter to avoid a clash must also not land on the getter of another rule (foo
renamed to foo_ next to rule foo_), and a rule must keep one getter name in all
the contexts that reference it.
PHP method names are case-insensitive, so the PHP target cannot yet generate
both foo() and Foo().

[type]
Parser

[grammar]
grammar T;

s
    : renamedOntoRule ruleAndTokenList ruleListAndToken ruleAndRuleList tokenAndTokenList labeled labeled EOF {<writeln("$text")>}
    ;

renamedOntoRule
    : foo foo_ Foo
    ;

ruleAndTokenList
    : allFoo Foo Foo
    ;

ruleListAndToken
    : foo foo AllFoo
    ;

ruleAndRuleList
    : allFoo foo foo
    ;

tokenAndTokenList
    : AllFoo Foo Foo
    ;

labeled
    : '[' foo Foo ']' #withToken
    | '{' foo '}' #withoutToken
    ;

foo
    : Foo
    ;

foo_
    : Foo
    ;

allFoo
    : Foo
    ;

AllFoo : 'all' ;
Foo : [a-z]+ ;
WS : [ \t\r\n]+ -> skip ;

[start]
s

[input]
a b c d e f g h all i j k all l m [n o] {p}

[output]
"""abcdefghallijkalllm[no]{p}
"""

[skip]
PHP
